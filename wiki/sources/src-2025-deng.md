# Towards Machine Learning-based Model Predictive Control for HVAC Control in Multi-Context Buildings at Scale via Ensemble Learning
- 年份與來源：2025 | arXiv:2505.02439
- 核心問題：多建築場景下熱力學模型變數選擇與資料收集成本高，難以擴展 ML-based MPC。
- 方法與模型：Ensemble Learning、Hierarchical Reinforcement Learning、Bayesian Optimization (BOA)、Gaussian Processes (GP)、Model Predictive Control (MPC)。
- 實驗與指標：多房間資料集（65 間房，80% 即 52 間房訓練基礎模型）進行離線與實地驗證，評估室內溫度預測與控制效能。
- 限制與缺口：跨不同建築結構與感測器配置時，權重與變數適應仍需驗證。
